# Requisitos Não Funcionais — StockFlow

Este documento apresenta os requisitos não funcionais atualmente definidos para o sistema StockFlow.

| ID | Requisito Não Funcional | Categoria |
|---|---|---|
| RNF01 | Proteger as funcionalidades administrativas por meio de autenticação | Segurança |
| RNF02 | Permitir controle de acesso às funcionalidades administrativas | Controle de acesso |
| RNF03 | Armazenar senhas utilizando mecanismo seguro de hash | Segurança |
| RNF04 | Preservar a integridade e consistência dos dados armazenados | Integridade dos dados |
| RNF05 | Evitar duplicidades durante os processos de importação e reimportação | Integridade dos dados |
| RNF06 | Manter rastreabilidade sobre os arquivos e registros importados | Rastreabilidade |
| RNF07 | Processar os arquivos CSV em tempo adequado à utilização do sistema | Desempenho |
| RNF08 | Apresentar interfaces organizadas e de fácil utilização | Usabilidade |
| RNF09 | Permitir a consulta eficiente de centenas de medicamentos | Usabilidade |
| RNF10 | Manter o módulo público disponível para consulta pela Internet | Disponibilidade |
| RNF11 | Permitir futuras expansões da aplicação e inclusão de novas unidades | Escalabilidade |
| RNF12 | Permitir manutenção e evolução dos módulos do sistema | Manutenibilidade |
| RNF13 | Permitir acesso ao módulo público pelos principais navegadores web atuais | Compatibilidade |
| RNF14 | Manter as configurações sensíveis fora do código-fonte versionado | Segurança |
| RNF15 | Preservar os dados originais importados quando necessários para rastreabilidade | Integridade dos dados |
