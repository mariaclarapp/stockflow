# Diagramas do StockFlow

Esta pasta contém os diagramas utilizados na modelagem do sistema StockFlow.

Sempre que possível, devem ser mantidos:

1. o arquivo-fonte editável do diagrama;
2. uma versão exportada para visualização.

## Organização

- `arquitetura/` — Arquitetura geral da solução.
- `casos-de-uso/` — Diagramas de casos de uso.
- `classes/` — Diagramas de classes.
- `der/` — Diagrama Entidade-Relacionamento.
- `sequencia/` — Diagramas de sequência.

## Formatos utilizados

Os diagramas podem utilizar diferentes formatos conforme a ferramenta empregada:

- `.puml` — PlantUML;
- `.dbml` — DBML utilizado no DER;
- `.png` — versão exportada para visualização.

## Diretriz

Os arquivos-fonte devem ser atualizados junto com suas respectivas imagens sempre que houver alteração na modelagem.
